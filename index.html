Agentic SWE Synthr

Synthr

Agentic SWE AI assistant · May 2026

An autonomous assistant that resolves GitHub tickets end-to-end — ingesting an issue, classifying intent, retrieving codebase context via hybrid RAG (dense + BM25 with RRF fusion and Cohere reranking, Tree-sitter AST-based chunking), generating and editing code, validating changes with automated test runs in Docker, and opening a PR via PyGitHub. A 6-agent LangGraph pipeline handles the whole workflow with structured Pydantic hand-offs, and GitHub-webhook-triggered Celery workers keep the vector index incrementally in sync with the live repo.
